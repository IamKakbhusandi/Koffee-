## 🛠️ Tech Stack & Architecture
This project serves as a showcase for high-quality Android engineering principles:
* **Language:** 100% Kotlin
* **UI Framework:** Jetpack Compose (Modern, declarative UI development)
* **Architecture:** MVVM (Model-View-ViewModel) paired with clean unidirectional data flow (UDF).
* **Concurrency:** Kotlin Coroutines & Asynchronous Flows for non-blocking UI operations.
* **Asynchronous Streams:** StateFlow and SharedFlow for real-time UI state tracking and event emission.
